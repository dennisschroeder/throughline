# Semantic Model and MCP Bootstrap

## Frozen execution graph

State starts as the accepted semantic-model plan and repository constraints.

```text
N0 Plan validator [validator]
  | plan scope is additive and non-goals remain false
  v
N1 Canonical ontology + source mappings [agent]
  | ontology/throughline.json exists and parses
  v
N2 Generator implementation [agent]
  | generator command exits 0 and generated bytes/digests are deterministic
  v
N3 Embedded semantic-model package [agent]
  | package validation returns a valid model
  v
N4 MCP bootstrap and get_semantic_model adapter [agent]
  | focused MCP contract tests pass
  v
N5 Fan-in: documentation and repository wiring [agent]
  | go generate and documented commands point at real paths
  v
N6 Verify: format -> vet -> build -> test -> CGO-free build [command]
  | all commands exit 0
  |-- exit != 0 --> N7 Local fix [agent] -- budget 3 --> N6
  |                 escape after third failed iteration: report exact output
  v
N8 Independent review [agent]
  | review result contains zero unresolved findings
  |-- findings > 0 --> N9 Review fix [agent] -- budget 5 --> N6
  |                    escape on repeated same finding after claimed fix or
  |                    fifth iteration: escalate with open findings
  v
N10 Delivery validator [validator]
  | acceptance checks true, generated output clean, diff in scope
  v
Done
```

N1 through N4 are sequential because each owns the input contract of the next node; they are not a
fan-out. N5 owns documentation and CI/release wiring after the implementation surfaces exist. N8 is
independent of authorship and reviews the complete diff. The verify-to-fix back-edge carries the
changed files and last command output; the review-to-fix back-edge carries each finding disposition.

## Actual outcomes

- N0 -> N1: predicate true; the plan stayed additive and did not reopen a documented non-goal.
- N1 -> N2: predicate true; canonical ontology parsed and source mappings resolved.
- N2 -> N3: predicate true; generator completed with deterministic normalized output and digests.
- N3 -> N4: predicate true; embedded model loaded and validated.
- N4 -> N5: predicate true; MCP tool and compact bootstrap were wired without persistence changes.
- N5 -> N6: predicate true; documentation and CI/release generation checks were added.
- N6 -> N7: taken once; initial focused checks exposed generator working-directory, package-declaration,
  and manifest issues. Each was repaired locally. Final N6 exit predicate was true for formatting,
  vet, build, full test, CGO-free build, generation drift, and diff hygiene.
- N6 -> N8: predicate true; all final verification commands exited 0.
- N8 -> N9: taken twice; review findings were fixed for source safety, artifact validation, release
  checks, MCP schema shape, and empty not-found arrays. The final review predicate was zero unresolved
  findings.
- N8 -> N10: predicate true; final review clean.
- N10 -> Done: predicate true; implementation acceptance checks passed. Delivery is local because no
  push, CI run, or merge was requested.

## Feedback

The graph was correctly sequential: ontology, generator, embedded runtime, and MCP contracts shared
the same evolving artifact boundary. The initial verify budget was not exhausted, and review exposed
more contract detail than the first tests covered; future work should add the planned exhaustive MCP
section and generator determinism tests.
