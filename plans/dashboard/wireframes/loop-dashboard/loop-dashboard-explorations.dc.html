5Inline returns — the loop rendered into the agent's chat

Agent-first control means most of the loop is read in the transcript, not the dashboard. Blocks never carry buttons — a chat transcript cannot hold a decision, so the only affordance is a deep link into the dashboard. 5a shows one in place; 5b–5g are the block set alone.
